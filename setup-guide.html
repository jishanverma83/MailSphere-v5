Google OAuth setup
Add your Google Client ID to enable Gmail sync.
  1. Open your Google Cloud Console.
  2. Create a web OAuth client ID.
  3. Add http://localhost:5173 as an authorized JavaScript origin.
  4. Update the value in js/config.js for googleClientId.
  5. Reload the app and click the Google sign-in button.

While MailSphere is in Google OAuth Testing mode, only approved Gmail accounts can sign in. To request access, contact jishanverma42@gmail.com.
